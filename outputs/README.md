# SafeTriage Project Materials

This folder contains the main CA6117 project deliverables for SafeTriage.

## Deliverables

- `SafeTriage_Written_Report.docx` - written report in Word format.
- `SafeTriage_Written_Report.pdf` - rendered PDF copy of the written report.
- `SafeTriage_Presentation.pptx` - presentation deck with speaker notes and embedded prototype animation.
- `safetriage-agent-code.zip` - source-code archive.
- `safetriage-demo.gif` - animated prototype walkthrough used in the README and presentation.

## Rendered Evidence

- `SafeTriage_Presentation/` - rendered slide PNGs for quick visual review.
- `SafeTriage_Presentation.pptx.inspect.ndjson` - deck inspection output used during verification.
